# ContextLoom v2.5.0

**A context-aware coding agent harness — TUI + GUI, prebuilt for every platform.**

## Highlights

- **Multi-round thinking engine (M1–M12).** A brand-new `internal/thinkmgr` gives the agent
  a proper thinking lifecycle: round model (`explore / execute / verify / refine`),
  per-task complexity assessment, task-level policies, continuation nudges, and a
  guardrail that intercepts premature wrap-ups. All three executor paths
  (`Run / RunStream / RunStreamWithBudget`) are wired up, with full trace reporting and a
  `/think` command in the TUI. **Off by default (`thinking.*` config, 9 fields) — zero
  regression when disabled.**
- **Independent generation parameters.** `max_output_tokens`, `max_input_tokens`,
  `thinking_length` and `thinking_enabled` are now first-class settings — output limits are
  decoupled from context limits — plumbed end-to-end: config → model → modelgateway →
  runtime → GUI settings panel.
- **"Zombie stream" fixed for good.** Stopping a chat could previously resurrect itself when
  switching back to a project: stream buffers now use proper move semantics (merged
  buffers are removed from the connection buffer, archived entries carry `streamId`,
  stopped foreground streams are never archived). Fixed on both the Go side (pre-registered
  send streams, guaranteed `interrupted` finalization) and the GUI side (`app.js`).
- **Compaction no longer blocks or kills conversations.** Progressive compaction moved out
  of `historyMu` (O(1) snapshot under lock, CAS write-back outside), thinking chains are
  protected during compaction, and both manual & auto compaction now broadcast
  `ctx.compressed` so the frontend reloads the full history instead of showing truncated
  text.
- **Session isolation hardening.** Checkpoints are validated by `SessionID`; `memory.Load`
  returns shallow copies to prevent parallel streams from polluting the cache.
- **GUI launcher improvements.** Same-directory backend lookup now prefers the current
  platform's suffixed binary name with cross-platform fallback, keeping the strict
  `<GOOS>-<GOARCH>` whitelist.
- **Full build matrix re-verified**: 24-target TUI (darwin / linux / windows / freebsd /
  netbsd / openbsd / dragonfly / solaris / aix) + GUI binaries for macOS (arm64 & amd64)
  and Windows (amd64 & arm64, GUI subsystem — no console window on double-click).

## Install

```bash
# macOS / Linux TUI — no Go toolchain needed
chmod +x contextloom-linux-amd64 && ./contextloom-linux-amd64 --version
```

```powershell
# Windows GUI — keep the backend beside the launcher
# contextloom-gui-windows-amd64.exe + contextloom-windows-amd64.exe in the same folder
.\contextloom-gui-windows-amd64.exe
```

The GUI locates its `contextloom` backend next to its own executable first; override with
`CONTEXTLOOM_BIN=/path/to/contextloom` if they live apart.

## Verify

```bash
./contextloom-darwin-arm64 --version    # contextloom v2.5.0
sha256sum -c SHA256SUMS                 # integrity of all attached binaries
```

## Known limitations

- **Plan 9** is not shipped: the upstream `charmbracelet/x/term` dependency has no plan9
  implementation (`undefined: state/isTerminal/makeRaw`), so the TUI cannot link there.
- **Linux GUI** must be built on target (WebView/CGO), see above.

# ContextLoom v2.5.0（中文）

**上下文感知的编码 Agent 框架 —— TUI + GUI，全平台预编译。**

## 重点更新

- **多轮思考引擎（M1–M12）正式落地。** 全新 `internal/thinkmgr` 为 Agent 提供完整的思考
  生命周期：轮次模型（explore / execute / verify / refine）、任务复杂度评估、任务级策略、
  续思提示（nudge）、以及收尾拦截护栏（guard）。执行器三条路径
  （`Run / RunStream / RunStreamWithBudget`）全部接线，支持 trace 上报与 TUI `/think` 命令。
  **默认全关（`thinking.*` 配置共 9 个字段）——关闭时零回归。**
- **生成参数独立化。** `max_output_tokens`、`max_input_tokens`、`thinking_length`、
  `thinking_enabled` 升级为一等公民设置——输出上限与上下文上限解耦——全链路打通：
  config → model → modelgateway → runtime → GUI 设置面板。
- **彻底修复「停止对话复活」。** 此前停止对话后在切回项目时流可能"复活"：流缓冲现改用
  移动语义（合并后从连接缓冲移除、归档条目补全 `streamId`、已停止前台流不再归档）。
  Go 侧（send 流预注册前移、interrupted 收尾必达）与 GUI 侧（`app.js`）双向修复。
- **压缩不再卡死/中断对话。** 渐进压缩移出 `historyMu`（锁内 O(1) 快照 + 锁外 CAS 回写），
  思考链在压缩时受保护，手动/自动压缩统一广播 `ctx.compressed`，前端自动重拉完整历史
  而非显示截断文本。
- **会话隔离加固。** 检查点按 `SessionID` 归属校验；`memory.Load` 返回浅拷贝，
  防止并行流污染缓存。
- **GUI 启动器改进。** 同目录后端查找优先命中当前平台后缀产物名，跨平台兜底，
  同时保留严格的 `<GOOS>-<GOARCH>` 白名单校验。
- **全构建矩阵重新验证**：24 目标 TUI（darwin / linux / windows / freebsd / netbsd /
  openbsd / dragonfly / solaris / aix）+ GUI 产物（macOS arm64 & amd64、Windows
  amd64 & arm64，GUI 子系统——双击无黑窗）。
